# base-hertz

Official base **Hertz HTTP** service template — standard layered layout with JWT authentication, API signature verification, and idempotency support.

## Overview

`base-hertz` is the foundation template for building HTTP services with CloudWeGo Hertz framework. It provides essential security and reliability features out of the box:

- ✅ **JWT Authentication** - Bearer token validation
- ✅ **API Signature** - HMAC signature verification (optional)
- ✅ **Idempotency** - Prevent duplicate requests (optional)
- ✅ **Health Checks** - Kubernetes-ready liveness/readiness probes
- ✅ **Fine-grained Error Codes** - Aligned with go-framework v0.2.1

**Note:** This template does NOT include rate limiting. For services that need rate limiting, use `ratelimit-hertz` instead.

## Requirements

This template requires ncgo that includes PR #71 (commit `0d5a8df`). The per-service router/handler files are generated by ncgo's `loop_service` overlay from `idl/app/{service}.proto`.

## Quick Start

```bash
# With database support (recommended)
ncgo new my-api --module github.com/acme/my-api --kind hertz --db postgres --template base-hertz

# Without database support
ncgo new my-api --module github.com/acme/my-api --kind hertz --template base-hertz
```

## Middleware Stack

### 1. JWT Authentication (Required)

All routes under `/api/v1/*` (except health checks) require a valid JWT token:

```bash
curl -H "Authorization: Bearer <token>" http://localhost:8080/api/v1/resources
```

**Configuration:**
```yaml
jwt:
  secret: "your-256-bit-secret"
  access_token_ttl_seconds: 3600
  refresh_token_ttl_seconds: 86400
```

### 2. API Signature (Optional)

For open API scenarios, enable HMAC signature verification:

```yaml
auth:
  signature:
    enabled: true
    static_secret: "your-app-secret"
    header_app_key: "X-App-Key"
    header_timestamp: "X-Timestamp"
    header_nonce: "X-Nonce"
    header_signature: "X-Signature"
```

**Error Codes:**
- `10007` (401) - Missing signature headers
- `10018` (401) - Signature timestamp expired
- `10019` (403) - Invalid signature
- `10023` (403) - Invalid AppKey

### 3. Idempotency (Optional)

Prevent duplicate POST/PUT/DELETE requests:

```yaml
idempotency:
  enabled: true
  header: "Idempotency-Key"
  backend: "memory"  # or "redis"
```

**Error Codes:**
- `10203` (400) - Missing Idempotency-Key
- `10204` (409) - Idempotency conflict

## Error Codes

All error codes are aligned with `go-framework v0.2.1`:

| Code | HTTP | Message | Description |
|------|------|---------|-------------|
| 10002 | 401 | auth_failed | Generic auth failure |
| 10007 | 401 | signature_missing | Missing signature headers |
| 10018 | 401 | signature_expired | Signature timestamp expired |
| 10019 | 403 | signature_invalid | Invalid signature |
| 10020 | 401 | token_missing | Missing JWT token |
| 10021 | 401 | token_invalid | Invalid JWT token |
| 10022 | 401 | token_expired | JWT token expired |
| 10023 | 403 | app_key_invalid | Invalid AppKey |
| 10203 | 400 | idempotency_key_missing | Missing Idempotency-Key |
| 10204 | 409 | idempotency_conflict | Idempotency conflict |

## API Routes

### Public Routes

- `GET /healthz` - Liveness probe
- `GET /readyz` - Readiness probe

### Protected Routes (JWT Required)

Example CRUD endpoints:

```
GET    /api/v1/resources      # List resources
GET    /api/v1/resources/:id  # Get resource
POST   /api/v1/resources      # Create resource
PUT    /api/v1/resources/:id  # Update resource
DELETE /api/v1/resources/:id  # Delete resource
```

## Adding Infrastructure

After creating your project, add infrastructure components:

```bash
# Redis (for idempotency backend)
ncgo add infra redis --root .

# Structured logging
ncgo add infra logging --root .

# Observability (OpenTelemetry)
ncgo add infra observability --root .
```

## Configuration

Edit `conf/dev/conf.yaml`:

```yaml
server:
  http:
    port: "8080"

database:
  enabled: true
  dsn: "postgres://user:pass@localhost:5432/mydb?sslmode=disable"

redis:
  addrs:
    - "127.0.0.1:6379"

jwt:
  secret: "your-secret-key"
  access_token_ttl_seconds: 3600

auth:
  signature:
    enabled: false  # Enable for open APIs

idempotency:
  enabled: false  # Enable to prevent duplicates
```
